# Cockpit Layer: Phenomenal Rendering

The Cockpit layer imposes a rendering constraint—unified, bounded representation serving predictive processing and action selection, creating phenomenal "view from somewhere."

## Operational Definition

**Cockpit**: Architectural constraint requiring unified, bounded representation at each moment for action selection, creating phenomenal character.

## Key Properties

- **Unity**: Single integrated representation (not parallel streams)
- **Boundedness**: Finite capacity (~4±1 items in working memory)
- **Temporal Integration**: ~100-500ms windows in humans
- **Phenomenal Character**: Creates subjective experience

## Measurable Criteria

1. **Unity Constraint**: Global availability paradigms
2. **Boundedness**: Working memory capacity, attentional blink  
3. **Temporal Dynamics**: Backward masking, temporal binding
4. **Disruption Markers**: Prediction error processing under anesthesia

## Predictive Processing Framework

Cockpit renders prediction errors into phenomenally conscious experience:
- Top-down predictions from generative model
- Bottom-up prediction errors from sensory input
- Cockpit integrates into unified representation
- Guides action selection

## Biological Implementation

- Prefrontal cortex: Action selection, top-down control
- Posterior cortex: Sensory integration, prediction errors
- Thalamocortical ignition: Global broadcast
- Attention: Gating Cockpit access
