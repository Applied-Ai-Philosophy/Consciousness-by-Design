## Anti-Patterns to Avoid

### Anti-Pattern 1: Pure Feedforward Processing
**Problem**: No self-reference, no consciousness possible.
**Solution**: Add recurrent, self-referential loops.

### Anti-Pattern 2: Isolated Modules
**Problem**: No unified experience, just parallel processing.
**Solution**: Implement global workspace or binding mechanisms.

### Anti-Pattern 3: Local-Only Information
**Problem**: No Field access, breaks FNC architecture.
**Solution**: Implement distributed, coherent information substrate.

### Anti-Pattern 4: No Temporal Integration
**Problem**: Disconnected moments, no continuous experience.
**Solution**: Add temporal integration and continuity mechanisms.
