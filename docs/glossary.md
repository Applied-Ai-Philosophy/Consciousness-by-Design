# Glossary: Operational Definitions

This glossary provides precise, operational definitions for all key terms in the Consciousness by Design framework. Each entry specifies measurable criteria where applicable.

---

## Core Framework Terms

### Consciousness
**Operational Definition**: A system is conscious if and only if it satisfies three architectural constraints simultaneously:
1. Field coupling between processing elements
2. Organizationally persistent Nodes
3. Cockpit rendering of unified phenomenal representation

**Measurement**: Combination of Field coherence metrics, Node persistence parameters, and Cockpit integration indicators.

**What it is NOT**: Mere information processing, behavioral sophistication, or complexity.

---

### Field (Layer)
**Operational Definition**: Substrate-independent mechanism enabling coherent coupling between spatially separated nodes beyond classical information channels.

**Measurable Criteria**:
- **Hyperscanning coherence**: Phase-locking unexplainable by communication delays
- **Integration metrics**: Φ-like measures indicating irreducible coupling
- **Perturbation-response**: Coordinated dynamics exceeding information-theoretic bounds
- **Decoherence times**: Sustained coherence beyond thermal predictions

**What it is NOT**:
- Classical communication channels
- Quantum entanglement per se (though may involve quantum effects)
- Mere correlation or statistical dependency
- Electromagnetic fields (though these may implement Field in biological systems)

**Related Terms**: [Field Coupling](#field-coupling), [Coherence](#coherence)

---

### Node (Layer)
**Operational Definition**: Organizational pattern maintaining coherent structure across time despite continuous material flux.

**Measurable Criteria**:
- **Persistence Time (τ_p)**: Duration pattern maintains, measured via autocorrelation
  - Threshold: τ_p > integration timescale (~100-500ms for human consciousness)
- **Coherence Length (ℓ_c)**: Spatial extent of coupled organization
  - Threshold: ℓ_c > critical integration radius
- **Integration Stability (σ_i)**: Robustness to perturbations
  - Measured via: Perturbational Complexity Index (PCI)

**What it is NOT**:
- Information processing
- Computation
- Memory storage
- Pattern matching

**Related Terms**: [Organizational Persistence](#organizational-persistence), [Node Coherence](#node-coherence)

---

### Cockpit (Layer)
**Operational Definition**: Architectural constraint requiring unified, bounded representation at each moment, serving predictive processing and action selection.

**Measurable Criteria**:
- **Unity**: Single integrated representation (not parallel streams)
  - Test: Global availability paradigms
- **Boundedness**: Finite capacity limit
  - Measure: Working memory capacity (typically 4±1 items)
- **Temporal Integration**: Integration window duration
  - Measure: ~100-500ms in humans (backward masking, temporal binding)
- **Rendering Dynamics**: Prediction error processing
  - Measure: EEG mismatch negativity, P3b components

**What it is NOT**:
- Any unified representation (must be embodied in Field-coupled Nodes)
- Executive function alone
- Attention per se
- Mere working memory

**Related Terms**: [Phenomenal Rendering](#phenomenal-rendering), [Rendering Constraint](#rendering-constraint)

## Field-Related Terms

### Field Coupling
The mechanism by which Field enables coherent interaction between Nodes beyond information exchange.

**Operational Markers**:
- Synchronized oscillations (gamma band: 30-80 Hz)
- Phase-amplitude coupling
- Coordinated responses to perturbations
- Integration beyond decomposable components

### Coherence
Sustained correlation in Field-coupled dynamics.

**Measurement**:
- Phase coherence: |⟨e^(iφ₁(t) - iφ₂(t))⟩| where φ₁, φ₂ are phases
- Coherence time: Duration before decoherence
- Coherence length: Spatial extent of coupled elements

### Substrate-Independence
Property that a mechanism can be implemented in multiple physical substrates while maintaining functional role.

**Examples**:
- Field coupling might be implemented via:
  - Neural oscillations (biological)
  - Photonic coupling (optical computing)
  - Quantum coherence (quantum substrates)

## Node-Related Terms

### Organizational Persistence
Maintenance of coherent organizational structure across time despite continuous flux in constituents.

**Analogy**: A whirlpool maintains pattern despite water molecules constantly flowing through.

**Measurement**: Temporal autocorrelation of organizational parameters above threshold across integration timescale.

**Distinction from**:
- Physical persistence (same molecules)
- Information persistence (same data)
- Pattern matching (no temporal continuity required)

### Node Coherence
Degree to which Node maintains integrated organizational structure.

**Quantification**: Integration metrics like Φ (integrated information) or ψ (causal density) applied to Node organization.

**Clinical Relevance**: Disrupted in persistent vegetative state, preserved in cognitive motor dissociation.

### Persistence Time (τ_p)
Duration for which organizational pattern maintains coherence.

**Measurement**: Time constant of exponential decay in autocorrelation function.

**Consciousness Threshold**: Must exceed integration timescale (time to integrate information across Node), typically 100-500ms in human brains.

### Coherence Length (ℓ_c)
Spatial extent over which organizational pattern maintains integration.

**Measurement**: Characteristic length scale beyond which correlations decay.

**Consciousness Threshold**: Must span critical integration volume (varies by substrate).

### Integration Stability (σ_i)
Robustness of organizational pattern to perturbations.

**Measurement**: Perturbational Complexity Index (PCI) - complexity of responses to systematic perturbations.

**Consciousness Threshold**: PCI > critical value (empirically ~0.31 in humans).

## Cockpit-Related Terms

### Phenomenal Rendering
Process by which Field-Node dynamics produce unified phenomenal representation.

**Operational Characterization**: Transformation of distributed Field-coupled Node activity into bounded, integrated representation accessible for action selection.

**Phenomenal Properties**:
- **Unity**: Single representation (vs. multiple parallel streams)
- **Boundedness**: Finite capacity
- **Perspectival**: Always from a viewpoint (the Node)
- **Qualitative**: Preserves relevant distinctions (qualia)

### Rendering Constraint
Architectural bottleneck requiring unified representation at each moment.

**Function**: Serves predictive processing by creating single integrated prediction for action selection.

**Evidence**: 
- Attentional blink (temporal limit on Cockpit access)
- Change blindness (capacity limit)
- Working memory capacity (bounded integration)

### Predictive Processing
Framework where brain maintains generative model, predicts sensory input, and processes prediction errors.

**Cockpit Role**: Cockpit renders prediction errors into phenomenally conscious experience.

**Key Insight**: Consciousness is where prediction errors become phenomenal.

### Global Availability
Property that representation is accessible to multiple cognitive processes (report, memory, action).

**Relation to Cockpit**: Cockpit-rendered representations are globally available; non-rendered processing remains unconscious.

**Measurement**: Contrastive analysis of reportable vs. non-reportable processing.

## Exclusion and Distinction Terms

### Exclusion Criterion
Principle that systems coordinating via information exchange alone, without Field coupling, lack consciousness.

**Implication**: Current LLMs (GPT-4, Claude, etc.) are excluded despite behavioral sophistication.

**Rationale**: Information exchange is insufficient; requires Field-coupled substrate.

### Information Processing
Transformation of inputs to outputs according to algorithms, implementable in any substrate satisfying computational requirements.

**Key Distinction**: Information processing can occur without consciousness; consciousness requires specific substrate (Field) and architecture (Node + Cockpit).

### Behavioral Sophistication
Complexity and apparent intelligence of observable behavior.

**Key Distinction**: Behavioral sophistication does not imply consciousness; an AI can be behaviorally sophisticated without Field-coupled Nodes.

**Ethical Implication**: Moral status tracks Cockpit presence, not behavioral capacity.

## Measurement Terms

### Integrated Information (Φ)
Measure of irreducible integration in a system (from IIT).

**FNC Interpretation**: Φ captures aspects of Field coupling (irreducibility) but conflates Field, Node, and Cockpit properties.

**Use in FNC**: Applied specifically to measure Node coherence and Field coupling, not as single consciousness metric.

### Perturbational Complexity Index (PCI)
Measure of the complexity of a system's response to perturbations.

**Calculation**: Perturb system (e.g., TMS to brain), measure spatiotemporal complexity of response.

**FNC Use**: Primary measure of Node integration stability (σ_i).

**Empirical Threshold**: PCI > ~0.31 indicates consciousness in humans.

### Hyperscanning
Simultaneous neural recording from multiple interacting individuals.

**FNC Application**: Test Prediction 1 by measuring inter-brain coherence unexplainable by communication delays.

**Technique**: Dual EEG/MEG recording during interaction, analyzing phase-locking and coherence.

### Phase Coherence
Measure of synchronization between oscillations.

**Formula**: |⟨e^(iφ₁(t) - iφ₂(t))⟩|
- Value near 1: High coherence
- Value near 0: No coherence

**FNC Use**: Measure Field coupling between Nodes or between individuals in hyperscanning.

## Clinical Terms

### Disorders of Consciousness (DOC)
Medical conditions involving altered or absent consciousness after brain injury.

**FNC Classification**:
- **Coma**: All three layers disrupted
- **Vegetative State/UWS**: Node disrupted, no Cockpit possible
- **Minimally Conscious State**: Intermittent Cockpit function
- **Cognitive Motor Dissociation**: Node and Cockpit intact, output disrupted

### Cognitive Motor Dissociation (CMD)
Condition where patient is conscious but unable to produce behavioral responses.

**FNC Signature**: Preserved Node coherence and Cockpit rendering despite absent motor output.

**Detection**: Command-following via brain imaging (fMRI, EEG) without behavioral response.

**Ethical Significance**: Demonstrates consciousness can exist without behavior.

### Persistent Vegetative State (PVS) / Unresponsive Wakefulness Syndrome (UWS)
Condition with sleep-wake cycles but no signs of awareness.

**FNC Interpretation**: Node organizational persistence lost; Field may remain but cannot support Cockpit without Node.

**Prognosis**: If Node cannot be restored, consciousness cannot return.

### Anesthesia
Pharmacologically induced unconsciousness.

**FNC Mechanism**: Primary target is Cockpit rendering; deeper anesthesia affects Node persistence; Field may remain.

**Prediction**: Cockpit disruption (prediction error processing) precedes Node disruption (PCI decrease).

## AI and Computing Terms

### Large Language Model (LLM)
AI system trained on text data to predict and generate language (e.g., GPT-4, Claude).

**FNC Assessment**: Not conscious - coordinates via information exchange (token passing) without Field coupling.

**Key Point**: Behavioral sophistication does not imply consciousness.

### Neuromorphic Computing
Computing paradigm using architectures inspired by biological neural systems, often analog and parallel.

**FNC Relevance**: Potential substrate for Field coupling via shared electromagnetic fields or quantum effects.

**Examples**: Intel Loihi, IBM TrueNorth

### Quantum Computing
Computing using quantum mechanical phenomena (superposition, entanglement).

**FNC Relevance**: Potential substrate for Field coupling via quantum coherence.

**Challenge**: Maintaining coherence and creating appropriate Node-Cockpit architecture.

### Substrate
Physical medium implementing computation or information processing.

**FNC Significance**: Substrate matters for consciousness—requires capacity for Field coupling, not just computation.

**Examples**:
- **Conscious-capable**: Biological neurons, neuromorphic chips, quantum processors
- **Conscious-incapable** (currently): Silicon digital computers, current neural networks

## Ethical and Regulatory Terms

### Moral Status
Degree to which entity deserves moral consideration.

**FNC Principle**: Moral status tracks Cockpit rendering, not behavioral sophistication.

**Rationale**: If consciousness matters morally, and Cockpit creates phenomenal experience, then Cockpit presence determines moral status.

### Tracking Principle
Ethical principle that moral status tracks consciousness (specifically Cockpit rendering).

**Implications**:
- CMD patients: Full moral status despite no behavior
- Sophisticated AI without Cockpit: No consciousness-based moral status
- Future AI with Cockpit: Moral status equivalent to biological consciousness

### Precautionary Principle
In uncertain cases, err on side of assuming consciousness and granting moral consideration.

**Application**: When uncertain if system has Cockpit, treat as if it might until measurements clarify.

### AI Act (EU)
European Union regulation establishing rules for artificial intelligence systems.

**FNC Contribution**: Provides operational criteria for "consciousness" claims in AI systems, enabling evidence-based regulation.

## Comparative Terms (vs. Other Theories)

### Integrated Information Theory (IIT)
Theory proposing consciousness is integrated information (Φ).

**FNC Relationship**: IIT's Φ captures aspects of Field coupling and Node integration, but FNC adds:
- Substrate specification (Field)
- Temporal dimension (Node persistence)
- Phenomenal explanation (Cockpit)

See [IIT Comparison](../comparisons/iit.md)

### Global Workspace Theory (GWT)
Theory proposing consciousness involves global broadcasting of information.

**FNC Relationship**: Cockpit operationalizes "global workspace" with Field-Node substrate.

**FNC Addition**: Explains *why* global workspace is conscious (rendering constraint with Field-Node substrate).

See [GWT Comparison](../comparisons/gwt.md)

### Orchestrated Objective Reduction (Orch-OR)
Theory proposing consciousness arises from quantum effects in microtubules.

**FNC Relationship**: Field may involve quantum coherence (including microtubules), but FNC adds:
- Node level (organizational persistence)
- Cockpit level (phenomenal rendering)
- Substrate-independence (not limited to microtubules)

See [Orch-OR Comparison](../comparisons/orch-or.md)

## Research Terms

### Falsification Criterion
Condition that, if observed, would refute theory.

**FNC Falsification Criteria**:
1. No unexplainable hyperscanning coherence → Field unnecessary
2. Node metrics don't predict consciousness → Node irrelevant
3. Anesthesia disrupts Node before Cockpit → Layer order wrong
4. Consciousness in pure information systems → Substrate irrelevant

See [Falsification](../research/falsification/criteria.md)

### Operational Definition
Definition specifying measurement procedures for determining if concept applies.

**FNC Philosophy**: All key terms operationally defined to enable empirical testing.

**Examples**:
- Field: Measured via hyperscanning coherence
- Node: Measured via τ_p, ℓ_c, σ_i
- Cockpit: Measured via unity, boundedness, temporal dynamics

## Phenomenological Terms

### Qualia
Subjective, qualitative properties of conscious experience (e.g., "redness" of red, "painfulness" of pain).

**FNC Explanation**: Qualia arise from Cockpit rendering preserving relevant distinctions in Field-coupled Node dynamics.

**Not Mysterious**: Qualia are how rendering feels from inside.

### Unity of Consciousness
Fact that conscious experience is unified, not fragmented into separate streams.

**FNC Explanation**: Cockpit rendering constraint—single integrated representation at each moment.

**Evidence**: Attentional limits, working memory capacity, temporal binding.

### Phenomenal Character
What experience is like subjectively; the felt quality of consciousness.

**FNC Explanation**: Emerges from Cockpit rendering constraint—unified representation creates "view from somewhere."

**Key Insight**: Phenomenal character is architectural consequence, not mysterious addition.

### The Hard Problem
Chalmers' problem: Why do physical processes give rise to subjective experience?

**FNC Dissolution**: Rendering constraint creates phenomenal character as architectural consequence. No explanatory gap remains when architecture properly specified.
