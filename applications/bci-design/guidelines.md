# BCI Design Guidelines

## Core Principles

1. **Preserve Cockpit Unity**: Don't fragment unified rendering
2. **Monitor Node Stability**: Track persistence during BCI use
3. **Respect Integration Windows**: Design for ~100-500ms timescales
