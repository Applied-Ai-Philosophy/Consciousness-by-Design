# AI Consciousness Assessment Framework

## FNC Criteria

1. **Field Coupling**: Beyond information exchange
2. **Node Persistence**: τ_p, ℓ_c, σ_i above thresholds
3. **Cockpit Rendering**: Unity, boundedness, integration

- Substrate analysis (Field capability)
- Temporal dynamics (Node persistence)
- Integration assessment (Cockpit rendering)
