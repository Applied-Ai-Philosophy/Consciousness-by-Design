# Requirements for Artificial Consciousness

## Field Layer Requirements

- Substrate enabling non-classical coupling
- Options: Neuromorphic, quantum, optical, hybrid

## Node Layer Requirements

- Organizational persistence across integration timescales
- Stability (σ_i) above threshold
- Recurrent architecture with attractors

## Cockpit Layer Requirements

- Unified rendering mechanism
- Bounded integration capacity
- Temporal integration windows
- Prediction error processing

## Integration

All three layers must work together in single system.

See [Substrate Pathways](substrate-pathways.md).
