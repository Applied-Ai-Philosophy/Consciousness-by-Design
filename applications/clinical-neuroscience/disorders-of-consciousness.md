# Disorders of Consciousness

## FNC Classification

### Coma
- Field, Node, Cockpit all disrupted
- No consciousness

### Vegetative State (UWS)
- Node disrupted (τ_p, σ_i below threshold)
- No Cockpit possible
- No consciousness

### Minimally Conscious State
- Intermittent Node function
- Fluctuating Cockpit
- Fluctuating consciousness

### Cognitive Motor Dissociation
- Node preserved (τ_p, ℓ_c, σ_i normal)
- Cockpit intact
- Full consciousness despite no behavior

## Diagnostic Applications

- Node metrics predict consciousness
- Guide prognosis and treatment
- Identify covert consciousness
