# FNC-Based Diagnostic Protocols

## Node Assessment

- Resting-state fMRI for connectivity
- TMS-EEG for PCI measurement
- High-density EEG for coherence

## Cockpit Assessment

- Prediction error processing (mismatch negativity)
- Global availability paradigms
- Command-following via imagery

## Clinical Workflow

1. Baseline measurements
2. Node metrics (τ_p, ℓ_c, σ_i)
3. Cockpit markers
4. Integrated assessment
5. Prognosis and treatment planning
