# Anesthesia and Consciousness

## FNC Mechanism

### Light Anesthesia
- Cockpit disrupted first
- Node partially preserved
- Prediction error processing disrupted

### Deep Anesthesia  
- Node disrupted (τ_p, σ_i reduced)
- No Cockpit possible
- Complete unconsciousness

### Emergence
- Node recovers first
- Then Cockpit rendering
- Consciousness returns

## Monitoring Applications

- Track Cockpit markers (prediction error)
- Monitor Node persistence (PCI)
- Prevent intraoperative awareness
