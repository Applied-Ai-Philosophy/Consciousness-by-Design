## [1.0.0] - 2026-01-02

### Added

#### Repository Structure
- Initial comprehensive repository structure
- Root-level files: README.md, CONTRIBUTING.md, CITATIONS.md, LICENSE, CHANGELOG.md
- Documentation directory (/docs) with paper, summary, glossary, FAQ, and roadmap
- Theory directory (/theory) with detailed layer specifications
- Applications directory (/applications) with BCI, AI, clinical, and policy subdirectories
- Research directory (/research) with predictions, experimental designs, and falsification criteria
- Ethics directory (/ethics) with case studies and principles
- Comparisons directory (/comparisons) with theory comparisons
- GitHub templates for issues and pull requests

#### Core Framework (Version 1.0)
- **Field-Node-Cockpit (FNC) architecture**: Three-layer operational ontology for consciousness
- **Field Layer**: Substrate-independent coherent coupling mechanism
- **Node Layer**: Organizational persistence specification with measurable criteria
- **Cockpit Layer**: Phenomenal rendering constraint definition

#### Theoretical Components
- Integration model explaining why three layers are necessary and sufficient
- Exclusion principles clarifying what FNC rules out (current LLMs, coordination-only systems)
- Operational definitions for all key concepts

#### Research Program
- **Four core predictions**:
  1. Hyperscanning: Field coupling beyond communication channels
  2. Covert consciousness: Node coherence markers in non-communicative patients
  3. Prediction error: Cockpit disruption patterns under anesthesia
  4. Moral intuitions: Ethical judgments tracking cockpit rendering
- Experimental design templates
- Falsification criteria for each prediction

#### Applications
- **BCI Design**: Guidelines, safety constraints, assessment protocols
- **AI Consciousness**: Assessment framework, current systems analysis, requirements, substrate pathways
- **Clinical Neuroscience**: Disorders of consciousness, anesthesia, diagnostic protocols
- **Regulatory Policy**: AI governance, ethics guidelines, risk assessment

#### Ethics Framework
- Tracking principle: Moral status tracks cockpit rendering
- Case studies: CMD patients, anesthesia, PVS, brain death, AI rights
- Broader ethical implications

#### Comparisons
- Detailed comparisons with IIT, GWT, and Orch-OR
- Synthesis showing how FNC integrates insights from existing theories

#### Documentation
- Comprehensive README with audience-specific quick start guides
- Contribution guidelines with code of conduct
- Complete bibliography with 60+ references in multiple citation formats
- CC BY 4.0 license for open academic collaboration

#### GitHub Infrastructure
- Issue templates for: research questions, experimental results, theoretical refinements, application cases, falsification evidence
- Pull request template
- Structured contribution workflow

### Design Principles

- **Operational grounding**: All concepts defined with measurable criteria
- **Falsifiability**: Clear empirical predictions that can be tested
- **Cross-disciplinary accessibility**: Documentation tailored for neuroscientists, AI researchers, philosophers, policymakers, and clinicians
- **Collaborative research**: Infrastructure for community contributions and empirical testing
