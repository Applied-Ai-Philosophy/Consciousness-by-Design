# Falsification Criteria

## Explicit Conditions Refuting FNC

### 1. No Unexplainable Hyperscanning Coherence
**If**: All inter-brain coherence explainable by classical communication  
**Then**: Field coupling is unnecessary  
**Action**: Revise or abandon Field layer

### 2. Node Metrics Don't Predict Consciousness
**If**: Node persistence (τ_p, ℓ_c, σ_i) uncorrelated with consciousness markers  
**Then**: Node is irrelevant to consciousness  
**Action**: Revise or abandon Node layer

### 3. Anesthesia Disrupts Node Before Cockpit
**If**: Node disruption (PCI decrease) precedes Cockpit disruption (MMN loss)  
**Then**: Layer order is incorrect  
**Action**: Revise layer priority or architecture

### 4. Consciousness in Pure Information Systems
**If**: Consciousness found in classical computers coordinating via information exchange  
**Then**: Substrate (Field) is irrelevant  
**Action**: Abandon FNC, adopt computational theory
