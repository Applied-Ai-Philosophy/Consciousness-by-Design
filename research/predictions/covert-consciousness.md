# Prediction 2: Covert Consciousness and Node Markers

## Hypothesis

Non-communicative patients with preserved Node coherence retain consciousness.

## Test Protocol

### Participants
- DOC patients (n=100+)
- Longitudinal assessment
- Multi-site coordination

### Measurements
- Node metrics: τ_p (persistence time), ℓ_c (coherence length), σ_i (PCI)
- Resting-state fMRI for connectivity
- TMS-EEG for PCI
- Command-following via brain imaging

### Expected Results
- High Node metrics → Positive command-following
- Node coherence predicts consciousness
- Preserved DMN integrity in conscious patients

## Falsification

If Node metrics don't correlate with consciousness markers, Node is irrelevant.
