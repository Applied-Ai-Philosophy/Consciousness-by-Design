# Prediction 3: Prediction Error and Anesthesia

## Hypothesis

Anesthetic agents disrupt Cockpit rendering of prediction errors before affecting Node persistence.

## Test Protocol

### Design
- Progressive propofol dosing
- Multiple agents (propofol, sevoflurane, ketamine)
- Recovery tracking

### Measurements
- Continuous EEG with ERPs
- Mismatch negativity (Cockpit marker)
- PCI (Node marker)
- Behavioral responsiveness

### Expected Results
- Cockpit disruption (MMN loss) precedes Node disruption (PCI decrease)
- Layer-specific anesthetic effects
- Predicted recovery sequence

## Falsification

If Node and Cockpit disrupt simultaneously, layer distinction is artificial.
