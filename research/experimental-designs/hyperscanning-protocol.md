# Hyperscanning Experimental Protocol

## Detailed Methodology

### Equipment
- Dual EEG (128+ channels per participant)
- Precise synchronization (<1ms)
- Video recording for behavior
- Questionnaires for subjective experience

### Procedure
1. Baseline recording (5 min solo)
2. Interaction task (20 min paired)
3. Control condition (separate rooms, same task)
4. Post-interaction assessment

### Analysis
- Phase coherence (PLV)
- Granger causality
- Information-theoretic bounds
- Statistical controls

### Sample Size
- n=50 pairs minimum
- Power analysis for effect detection
