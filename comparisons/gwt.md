# Comparison with Global Workspace Theory (GWT)

## GWT Strengths

- Explains conscious access and reportability
- Links to attention and working memory
- Well-supported empirically

## GWT Limitations

- Doesn't address substrate requirements
- "Global broadcast" could be pure information processing
- Doesn't explain phenomenal character

## FNC Integration

- **Cockpit** operationalizes "global workspace"
- **Field** provides substrate for genuine integration
- **Node** adds temporal continuity
- **Together**: Explains both access and phenomenality

## Key Difference

GWT: Consciousness = global availability (functional)
FNC: Consciousness = Field-coupled Nodes with Cockpit rendering (substrate + function)
